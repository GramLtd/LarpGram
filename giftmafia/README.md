# GiftMafia

Мини-приложение Telegram: NFT-кейсы, игры «Мины» и «Апгрейд», каталог всех NFT-подарков Telegram со всеми моделями.

## Запуск
1. `pip install -r requirements.txt`
2. Создайте `.env`: `BOT_TOKEN`, `WEBAPP_URL` (обязательно https, для теста: `cloudflared tunnel --url http://localhost:8000`), `ADMIN_TOKEN`, `ADMIN_CHAT_ID`
3. `uvicorn main:app --port 8000`
4. В @BotFather: Menu Button / Mini App -> WEBAPP_URL. Stars работают без доп. настройки.
5. Админка: WEBAPP_URL/admin (токен из ADMIN_TOKEN). ADMIN_CHAT_ID - ваш id, туда приходят заявки.

База теперь `giftmafia_v2.db` (схема изменилась, старая `giftmafia.db` не используется).

## Интерфейс
Нижнее меню: **Игры** (Мины, Апгрейд, Плинко), **Кейсы**, **Заработок** (рефералка), **Бонусы** (бесплатный «Подарок дня»).
Аватар справа сверху — профиль и инвентарь: вывод, продажа подарка на баланс, задания для подарка дня.

## Каталог NFT
- `static/gifts.json` — все NFT-подарки Telegram (123 коллекции, 7806 моделей) с редкостью моделей.
  Обновить после выхода новых подарков: `python tools/fetch_gifts.py`.
- Картинки моделей сервер один раз скачивает с `cdn.changes.tg` и отдаёт уменьшенными webp через `/img`.
  Данные — бесплатный API GiftChanges (api.changes.tg). Условие API: видимая благодарность в приложении,
  она оставлена одной строкой внизу профиля. Без неё автор API может закрыть доступ.
- Оценка NFT в ⭐ = floor коллекции в TON (`FLOORS` в main.py, остальные — `DEFAULT_FLOOR`) × `TON_STARS` × множитель редкости модели.
  Флоры приблизительные: поправьте под рынок и перезапустите — цены призов пересчитаются.

## Кейсы
- Собираются из каталога при запуске (`build_cases` в main.py), если поменялся `ECONOMY_VERSION`: «На сдачу», «50/50», «Премиум», «Коллекции» и бесплатный «Подарок дня».
  Призы - конкретные модели NFT и ⭐ на баланс. Веса подбираются так, чтобы средний возврат был `CASE_RTP` (85%) цены. Чтобы пересобрать кейсы после правки
  `FLOORS` или `CASE_RTP`, увеличьте `ECONOMY_VERSION` (правки цен и весов из админки при этом сбросятся).
  Дальше цены и шансы правятся в админке (там же можно добавить любую модель из каталога).
- Платные кейсы x1–x5 (`MAX_MULTI`), ⭐-призы сразу зачисляются на баланс, NFT попадают в инвентарь.
- Подарок дня раз в 24ч; NFT из него выводится после сторис + 5 сообщений друзьям.

## Мины
Поле 5×5, 1–24 мин. Множитель = `MINES_EDGE` (0.96) × честный коэффициент (3 мины: ×1,09 → ×1,25 → …).
Ставка балансом или подарком из инвентаря (по оценке), выигрыш в ⭐, максимум `MINES_MAX_WIN` за раунд.
Режим «Авто»: отмечаете клетки, они открываются по очереди и выигрыш забирается сам.
Поле генерируется на сервере заранее; клиент видит SHA-256 от поля и секрета, после игры они раскрываются (кнопка со щитом).

## Апгрейд
Ставите ⭐ или подарок из инвентаря и выбираете любую модель из каталога дороже ставки.
Шанс = ставка / цена цели × `UPGRADE_EDGE` (0.9), не больше `UPGRADE_MAX_CHANCE` (80%). Кнопки x1.5…x10 подбирают цель автоматически.

## Плинко
Ставка балансом, 8/12/16 рядов, риск низкий/средний/высокий. Путь шарика выбирается на сервере,
множители — классические таблицы, подогнанные до возврата `PLINKO_RTP` (около 95%). Максимальная ставка `PLINKO_MAX_BET`.

## Прочее
- Пополнение звёздами от `TOPUP_MIN` (50) до `TOPUP_MAX` (10 000).
- Рефералка: ссылка t.me/БОТ?startapp=r<id> (нужен Main Mini App в @BotFather). Друг зашёл: +5 ⭐, плюс 10% от его трат на кейсы.
- Сторис собирается автоматически из выигранного NFT (1080x1920), картинка модели кешируется в static/cache.

## Ограничения
- Telegram не даёт проверить, что сторис опубликована и кому ушли сообщения. Сервер считает нажатия
  (сторис + пауза 20с, 5 подтверждённых отправок через shareMessage). Накрутить можно, проверяйте заявки глазами.
- SQLite и один процесс - хватит для старта. Для нагрузки переходите на Postgres.
