# GiftMafia

Мини-приложение Telegram: NFT-кейсы, игры «Мины» и «Апгрейд», каталог всех NFT-подарков Telegram со всеми моделями.

## Запуск
1. `pip install -r requirements.txt`
2. Создайте `.env`: `BOT_TOKEN`, `WEBAPP_URL` (обязательно https, для теста: `cloudflared tunnel --url http://localhost:8000`), `ADMIN_TOKEN`, `ADMIN_CHAT_ID`
3. `apt install -y ffmpeg` (для видео-сторис), затем `uvicorn main:app --port 8000`
4. В @BotFather: Menu Button / Mini App -> WEBAPP_URL. Stars работают без доп. настройки.
5. Админка: WEBAPP_URL/admin — вход по ADMIN_TOKEN; вкладки «Обзор» (статистика и доход игр), «Заявки» (вывод подарков), «Кейсы» (цены, веса, добавление призов, расчёт возврата). ADMIN_CHAT_ID - ваш id, туда приходят заявки.

База теперь `giftmafia_v2.db` (схема изменилась, старая `giftmafia.db` не используется).

## Интерфейс
Нижнее меню: **Игры** (Мины, Апгрейд, Плинко), **Кейсы**, **Заработок** (рефералка), **Бонусы** (бесплатный «Подарок дня»).
Аватар справа сверху — профиль и инвентарь: вывод, продажа подарка на баланс, задания для подарка дня.

## Каталог NFT
- `static/gifts.json` — все NFT-подарки Telegram (123 коллекции, 7806 моделей) с редкостью моделей.
  Обновить после выхода новых подарков: `python tools/fetch_gifts.py`.
- Картинки моделей сервер один раз скачивает с `cdn.changes.tg` и отдаёт уменьшенными webp через `/img`.
  Данные — бесплатный API GiftChanges (api.changes.tg). Условие API: видимая благодарность в приложении,
  она оставлена одной строкой внизу профиля. Без неё автор API может закрыть доступ.
- У каждой модели своя цена в ⭐. Порядок: своя цена из админки → флор модели на Portals → формула (если модели нет в продаже).
  Цены с Portals (portal-market.com, открытый API) обновляются раз в сутки (`MARKET_EVERY`) и по кнопке в админке → «Цены».
  Курс TON → ⭐ берётся с CoinGecko, 1 ⭐ = `STAR_USD` ($0,015). После обновления цены призов пересчитываются,
  а шансы кейсов подгоняются под 85% автоматически (ручные веса из админки при этом перезаписываются).

## Кейсы
- Собираются из каталога при запуске (`build_cases` в main.py), если поменялся `ECONOMY_VERSION`: «На сдачу», «Тематические» (зимний, хэллоуин, любовь и др.), «50/50», «Премиум», «Коллекции» (20 коллекций) и бесплатный «Подарок дня» — всего 46 кейсов.
  Призы - конкретные модели NFT и ⭐ на баланс. Веса подбираются так, чтобы средний возврат был `CASE_RTP` (85%) цены. Чтобы пересобрать кейсы после правки
  `FLOORS` или `CASE_RTP`, увеличьте `ECONOMY_VERSION` (правки цен и весов из админки при этом сбросятся).
  Дальше цены и шансы правятся в админке (там же можно добавить любую модель из каталога).
- Платные кейсы x1–x5 (`MAX_MULTI`), ⭐-призы сразу зачисляются на баланс, NFT попадают в инвентарь.
- Подарок дня раз в 24ч: звёзды 1–25 и 8 самых дешёвых моделей, шанс NFT `FREE_NFT_CHANCE` (3%); NFT из него выводится после сторис + 5 сообщений друзьям.

## Мины
Поле 5×5, 1–24 мин. Множитель = `MINES_EDGE` (0.96) × честный коэффициент (3 мины: ×1,09 → ×1,25 → …).
Ставка балансом или подарком из инвентаря (по оценке), выигрыш в ⭐, максимум `MINES_MAX_WIN` за раунд.
Режим «Авто»: отмечаете клетки, они открываются по очереди и выигрыш забирается сам.
Поле генерируется на сервере заранее; клиент видит SHA-256 от поля и секрета, после игры они раскрываются (кнопка со щитом).

## Апгрейд
Ставите ⭐ или подарок из инвентаря и выбираете любую модель из каталога дороже ставки.
Шанс = ставка / цена цели × `UPGRADE_EDGE` (0.9), не больше `UPGRADE_MAX_CHANCE` (80%). Кнопки x1.5…x10 подбирают цель автоматически.

## Бонусы и заработок
- **Подарок дня** (вкладка «Бонусы»): если в админке задан канал (по умолчанию @GiftMafiaNFT), открыть можно только подписчикам.
- **Задания** (вкладка «Бонусы» → «Задания»), по умолчанию 3 ⭐ за каждое, добавляются и удаляются в админке → «Задания»:
  `channel` — подписка на канал (проверяется), `bot` — запустить этого бота /start (проверяется),
  `story` — выложить сторис, `link` — перейти по ссылке (эти два Telegram проверить не даёт, засчитываются после нажатия).
- **Поставь в ник** (вкладка «Заработок»): пользователь ставит тег (по умолчанию @GiftMafiaRobot) в имя и в описание,
  держит 24 часа и в течение 10 часов забирает награду; дальше каждые сутки снова. Награда зависит от уровня
  пользователя в Telegram: 0 / 1–4 / 5–9 / 10+ → 10 / 20 / 60 / 120 ⭐ (правится в админке).
  Бот проверяет имя, описание и уровень через getChat, поэтому пользователь должен один раз нажать /start в боте.
- **Важно:** чтобы бот мог проверять подписку, добавьте его администратором в канал. Если бот не может проверить,
  подарок дня открывается без проверки, а задание на подписку не засчитывается.

## Плинко
Ставка балансом, 8/12/16 рядов, риск низкий/средний/высокий. Путь шарика выбирается на сервере,
множители — классические таблицы, подогнанные до возврата `PLINKO_RTP` (около 95%). Максимальная ставка `PLINKO_MAX_BET`.

## Прочее
- Пополнение звёздами от `TOPUP_MIN` (50) до `TOPUP_MAX` (10 000).
- Рефералка: ссылка t.me/БОТ?startapp=r<id> (нужен Main Mini App в @BotFather). Друг зашёл: +5 ⭐, плюс 10% от его трат на кейсы.
- Сторис с выигрышем: видео 720x1280, 7 с (story.py), готовится в фоне сразу после выигрыша и кешируется в static/cache/stories.
  Нужен ffmpeg на сервере: `apt install -y ffmpeg`. Без ffmpeg выкладывается картинка того же дизайна.

## Оплата
Окно «Пополнить» — 4 способа, все зачисляют ⭐ на баланс и учитывают промокод:
- **Звёзды** — Telegram Stars, без настройки.
- **GRAM через TON Connect** — GRAM это бывший Toncoin. В админке → «Настройки» укажите кошелёк. Пользователь платит со своего кошелька
  (Tonkeeper и др.) с комментарием, сервер раз в 30 с проверяет входящие переводы через toncenter.com (`TONCENTER_KEY` в .env — необязательно).
- **xRocket** (GRAM или USDT) — в @xRocket → Rocket Pay создайте приложение и положите ключ в `.env`: `XROCKET_KEY=...`. Счёт открывается в @xRocket, оплата проверяется автоматически.
- **Подарки** — нужен аккаунт с Telegram Premium: Настройки → Telegram для бизнеса → Чат-боты → добавить этого бота (право «Просмотр подарков»).
  Пользователь дарит NFT этому аккаунту, бот зачисляет `gift_rate`% от оценки (по умолчанию 90%, правится в админке). Сами подарки остаются на аккаунте.
Курс ⭐ ↔ GRAM обновляется раз в сутки (CoinGecko). В мини-аппе цены подарков и кейсов можно показывать в ⭐ или GRAM (переключатель в фильтрах и в профиле).

## Промокоды, UTM, статистика
- Промокоды (админка → «Промокоды»): бонус % к следующему пополнению, лимит активаций и срок. Пользователь вводит код в профиле → «Промокод».
- UTM (админка → «UTM»): ссылки `t.me/БОТ?startapp=u_метка` и `t.me/БОТ?start=u_метка`; видно переходы, регистрации, платящих, пополнения и оборот.
- Дашборд: новые/активные пользователи, пополнения, оборот, доход за день/неделю/месяц/год, график, способы оплаты, игры и популярные кейсы.
  «Игроки» — поиск и карточка пользователя. В профиле мини-аппа — статистика игрока (лучший выигрыш, оборот, игры, любимая игра и кейс).
- Когда снова доступен «Подарок дня», бот пишет пользователю (выключается в «Настройках»).
- Аватарку бот ставит себе сам при первом запуске (`static/avatar.png`, `AVATAR_VERSION`).

## Заработок на комментариях
Вкладка «Заработок» → «Комментарии». Пользователь пишет комменты с упоминанием бота (под видео в TikTok с хэштегами
или в открытых Telegram-чатах) и присылает **скриншоты** в бота (`t.me/БОТ?start=cm` открывает правила).
- Сервер скриншоты не скачивает и не хранит — только `file_id` Telegram. Повтор того же скрина отсекается по `file_unique_id`.
- Каждый отчёт бот присылает альбомом в чат модерации (`cm_chat` в админке, по умолчанию ADMIN_CHAT_ID; бот должен быть в чате)
  с кнопками «Зачесть / С картинкой / Отклонить». То же можно сделать в админке → «Комменты» (картинки подгружаются только при просмотре).
- 1 скриншот = 1 коммент. Ставка `cm_rate` ⭐, с нашей картинкой +`cm_img_bonus`%, бонус дня от 100/500/1000/2000 зачтённых: +5/10/15/20%
  (обнуляется в 00:00 МСК), лимит `cm_max` скриншотов в день. Всё правится в админке → «Комменты».

## Премиум-эмодзи
Бот при старте загружает набор `emoji_set` (по умолчанию `GiftMafiaNFT`, t.me/addemoji/GiftMafiaNFT) и во всех своих сообщениях
заменяет обычные эмодзи на премиум из набора (`<tg-emoji>`), а эмодзи в начале текста кнопок - на иконку кнопки.
Сопоставление по эмодзи, который указан для каждой иконки при загрузке в @Stickers. Работает, если у владельца бота Telegram Premium.
В админке → «Настройки» видно, сколько загружено и каких эмодзи из текстов нет в наборе; кнопка «Обновить набор».

## Технические работы
Админка → «Настройки» → «Технические работы»: переключатель, текст, ориентировочное время окончания и список аккаунтов,
которым мини-апп доступен во время работ (по умолчанию @IbuyBalenciaga). Остальные видят экран «Технические работы»,
а сервер отвечает им 503 на все запросы мини-аппа. После выключения приложение у них откроется само (проверка раз в 20 с).

## Ограничения
- Telegram не даёт проверить, что сторис опубликована и кому ушли сообщения. Сервер считает нажатия
  (сторис + пауза 20с, 5 подтверждённых отправок через shareMessage). Накрутить можно, проверяйте заявки глазами.
- SQLite и один процесс - хватит для старта. Для нагрузки переходите на Postgres.
